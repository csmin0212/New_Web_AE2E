## 2. 다음에 넣으면 좋은 것 (추천 순)

1. **채팅 팔레트** — 캐릭터마다 자주 쓰는 굴림·대사를 버튼 목록으로. 코코포리아 유저가 가장 먼저 찾는 기능.
   시트의 스킬·판정에서 자동으로 만들고, 직접 추가도.
2. **로그 저장** — 세션 기록을 보기 좋은 HTML 한 장으로 내려받기 (테마 그대로). 위키·블로그에 올리기 좋게.
3. **BGM·효과음** — 장면마다 배경 음악, 컷인·크리티컬에 효과음. 음량은 각자 조절.
4. **표정 차분** — 캐릭터마다 표정 그림 여러 장, 대사 앞에 `[웃음]` 같은 꼬리표로 바꾸기.
5. **범위 표시** — 스퀘어·라인·전체 같은 범위 공격을 그리드에 겹쳐 보여 주고, 범위 안 토큰을 한 번에 대상으로.
6. **GM 레이어** — 플레이어에게 안 보이는 토큰 (매복·증원), 눌러서 등장.
7. **드롭품 굴림** — 에너미 시트의 드롭 표로 전투 후 자동 굴림 → 결과 카드.
8. **대기·지연 행동** — 아리안로드의 대기(차례 미루기) 버튼.
9. **캠페인 백업** — 캠페인 전체(캐릭터·저널·장면)를 파일로 내보내고 되살리기.
10. **경험치·성장 정리** — 세션 끝에 경험점 계산 표.

## 3. 이 툴만의 강점 (유지·강화)

- 아리안로드 규칙을 아는 자동화: 행동치 순서, 방어 경감, 코스트, 배드 스테이터스 클린업
- 에너미 정보가 화면이 아니라 **데이터 단계**에서 숨겨짐
- 비주얼노벨식 대화 무대와 페르소나식 연출
- 등장인물·지역 도감을 세션 배경·보여주기와 바로 연결
